# Python Function Assignments

A collection of foundational Python functions demonstrating parameters, return values, comparison operators, and default arguments.

## File Descriptions
* **greeting_script.py**: A refactored script that eliminates repetitive code by using a function to welcome multiple users to PLP.
* **double_number.py**: A function that takes a numeric input, multiplies it by two, and returns the calculated value.
* **pass_check.py**: A function that compares a student's score against a passing threshold of 50 and returns a boolean result.
* **flexible_greet.py**: A function utilizing default parameters to construct custom greetings with a name and a greeting word.

## Reflection
The hardest function to write was **`flexible_greet.py`** because it required understanding how default parameters function alongside mandatory positional arguments. It took extra care to ensure the string formatting perfectly matched the specific structural layout of punctuation, such as placing the comma and exclamation mark precisely around the dynamic variables.
